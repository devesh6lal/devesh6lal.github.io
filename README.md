# Digital Coast Solutions Website

This is a three-page static website prepared for GitHub Pages.

## Files

- `index.html` — Home page
- `services.html` — Software, website, IT and networking services
- `contact.html` — Contact details and enquiry form
- `assets/` — Logo, custom illustrations, CSS and JavaScript

## Publish on GitHub Pages

1. Create a public repository named exactly: `YOUR-GITHUB-USERNAME.github.io`
2. Open the repository and choose **Add file → Upload files**.
3. Open this website folder on your computer.
4. Select all files and folders inside it (`index.html`, `services.html`, `contact.html`, `assets`, etc.) and drag them into GitHub.
5. Choose **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then save.
9. Wait a few minutes and visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Update service information later

Edit `services.html` when you are ready to provide the full software and networking details. The page is already divided into these sections:

- Software Development
- Website Development
- Networking & Infrastructure
- IT Support
- System Installation & Configuration

## Contact form note

GitHub Pages cannot process server-side forms. This first version prepares an email in the visitor's email application. A service such as Formspree can be connected later for a fully online form.

## Custom domain later

After the GitHub address works, connect `digitalcoast.solutions` through GitHub Pages and Porkbun. Do not delete the existing Zoho MX and TXT records when changing website DNS records.
