# Digital Coast Solutions Launch Checklist

## 1. Confirm the public business information

- [ ] Company name is displayed exactly as intended: **Digital Coast Solutions**.
- [ ] Email `info@digitalcoast.solutions` can send and receive messages.
- [ ] Phone number `+679 281 8005` is correct and may be published.
- [ ] The FJ$1,000 website starter price and its conditions are still correct.
- [ ] Every service listed is currently available and accurately described.
- [ ] Add a physical address, service area or business hours only when they are meant to be public.
- [ ] Add any registered business name or registration number only after confirming the exact official wording.

## 2. Strengthen customer trust

- [ ] Add two or three real project examples when available.
- [ ] Add screenshots only with permission and remove private client information.
- [ ] Add genuine testimonials only after receiving client approval.
- [ ] Add professional social profile links only after those profiles are ready and actively monitored.
- [ ] Use the same logo, phone, email and business description across the website and business profiles.

## 3. Test the website before connecting the domain

- [ ] Home, Services, About, Contact and Privacy links work.
- [ ] Service “Learn more” links open the correct section.
- [ ] The mobile menu opens, closes and works with the Escape key.
- [ ] The enquiry form opens an email with all entered information.
- [ ] Phone and email links work on a phone.
- [ ] The website looks correct on desktop, tablet and mobile.
- [ ] No page contains draft wording, spelling errors or information that should remain private.
- [ ] Test an invalid address and confirm the custom 404 page appears.

## 4. Connect the official domain

- [ ] Verify `digitalcoast.solutions` under your GitHub profile **Settings → Pages** using GitHub's TXT record.
- [ ] Set `digitalcoast.solutions` under the repository **Settings → Pages → Custom domain** before changing website DNS.
- [ ] Take a screenshot of every existing Porkbun DNS record.
- [ ] Add the four GitHub Pages A records manually at Porkbun.
- [ ] Add the `www` CNAME pointing to `devesh6lal.github.io`.
- [ ] Keep all Zoho Mail MX, TXT, SPF, DKIM and verification records.
- [ ] Wait for the GitHub DNS check to pass.
- [ ] Turn on **Enforce HTTPS**.
- [ ] Test both `https://digitalcoast.solutions/` and `https://www.digitalcoast.solutions/`.

## 5. Verify email security

- [ ] Send a message from `info@digitalcoast.solutions` to Gmail and another provider.
- [ ] Reply to the message and confirm it returns to the correct mailbox.
- [ ] Confirm Zoho SPF, DKIM and domain verification records remain valid.
- [ ] Add a DMARC record when the email configuration has been checked.

## 6. Help search engines find the site

- [ ] Verify the domain in Google Search Console.
- [ ] Submit `https://digitalcoast.solutions/sitemap.xml`.
- [ ] Request indexing for the home page.
- [ ] Check the social preview image by sharing the official URL privately.
- [ ] Search for the company after indexing and confirm the title and description look correct.

## 7. Maintain the site

- [ ] Keep a local copy of the final website package.
- [ ] Use clear GitHub commit messages for every update.
- [ ] Review contact details and prices at least every three months.
- [ ] Update the privacy notice before adding analytics, an online form provider, accounts, payments or advertising.
- [ ] Never upload passwords, private keys, mailbox credentials or confidential client files to the public repository.
